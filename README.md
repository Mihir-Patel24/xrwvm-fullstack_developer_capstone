# Cars Dealership - Full Stack Web Application Capstone Project

Welcome to the **Cars Dealership** application repository. This project is developed as part of the IBM Full Stack Software Developer Capstone Project.

## Project Overview
Cars Dealership is a national car retailer in the United States. This web application provides:
- Dealership branch directory and filtering by state
- Dealer review exploration with automated sentiment analysis
- Customer review submission for authorized users
- Django backend, Node.js & Flask microservices, React frontend, SQLite & MongoDB databases
- Containerized deployment using Docker and Kubernetes CI/CD workflows
